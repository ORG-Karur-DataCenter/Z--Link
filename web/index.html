Getting started

Get your userID and API key

Z-Link needs these to put the references into your library. It takes about a minute, and you only do it once — Z-Link remembers them in this browser.

  1. Go to zotero.org and sign in. If you don't have an account yet, create one — it's free.
  2. Open zotero.org/settings/keys. You can also reach it from Settings → Security → Applications.
  3. Near the top you'll see a line reading “Your userID for use in API calls is …” followed by a number. That number is your userID — copy it into Z-Link. It is not your username or your email.
  4. Click Create new private key.
  5. Give it a name you'll recognise later, such as Z-Link.
  6. Tick Allow library access, and — this is the one people miss — tick Allow write access under Personal Library. Without write access Z-Link can read your library but cannot add anything, and the run will stop with a 403.
  7. Click Save Key.
  8. Zotero shows the key once. Copy it now and paste it into Z-Link. If you lose it, you can't view it again — just delete that key and create another.
Where the key is kept. In this browser's local storage, on this device. It is sent only to api.zotero.org, in a request header rather than a web address. It is never sent to Z-Link's own site, because Z-Link has no server.
If you share this computer, treat the key like a password. You can revoke it at any time from the same settings page, and any key you revoke stops working immediately.

Install the ODF Scan plugin

You probably do not need this. The main download, Your manuscript, with live citations, already contains real Zotero citations — open it in Word and they work. This second route exists for LibreOffice users and for anyone who wants the markers to check before they become citations.

One caution: if your manuscript contains images, ODF Scan can write a citation into a picture's internal XML and produce a file Word refuses to open. That is a limitation of the plugin, not of your document — the main download is unaffected.

The ODF Scan copy is a .docx where every citation is a Scannable Cite marker — text like { | Marmot, (2005) | | |zu:1234567:ABCD1234}. The plugin turns those markers into live Zotero citations.

You only install it once. It needs Zotero 7 or newer.

.xpi · 49 KB · saves to your computer

A verbatim copy of the plugin by Sebastian Karcher and Frank Bennett, AGPL-3.0-or-later, source at Juris-M/zotero-odf-scan-plugin. Newer versions appear on its releases page.

  1. Click the button above to save zotero-odf-scan-v3.2.1.xpi, most likely into your Downloads folder. If your browser instead offers to install it and then calls it corrupted, it has mistaken it for a browser extension — right-click the button and choose Save link as… instead.
  2. Open Zotero on your computer.
  3. Go to Tools → Plugins. (On older versions this menu is called Add-ons.)
  4. Click the gear icon ⚙ at the top right of the Plugins window, then choose Install Plugin From File…
  5. Change the file filter to show all files if the .xpi is greyed out, select the .xpi you downloaded, and click Open.
  6. Restart Zotero if it asks. ODF Scan for Zotero should now be listed under Plugins.

Run the scan on your document

  1. Make sure the run finished and you downloaded the ODF Scan copy from Z-Link.
  2. In Zotero, go to Tools → ODF Scan.
  3. For File type, choose ODF (to citations) — that is the direction that turns markers into live citations.
  4. For Input File, click Choose File… and pick the .docx you downloaded from Z-Link.
  5. For Output File, choose where to save the converted document. Keep it separate from the input so you still have the original if anything looks wrong.
  6. Click Next, let it work, then Finish.
  7. Open the output document. Your citations are now live Zotero citations, and you can insert a bibliography and change citation style from Zotero's word-processor toolbar.
Anything marked {NEEDS REVIEW: n} is a reference Z-Link could not confirm. Those stay as plain text on purpose — a visible gap is safer than a confident link to the wrong paper. Use the review step on the results page to decide them, then rebuild.
Word or LibreOffice? ODF Scan produces a document with live citation fields. Zotero's word-processor plugin has to be installed for your editor for those to be editable — that comes with Zotero itself, under Settings → Cite → Word Processors.
